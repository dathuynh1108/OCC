# Backup asset attribution

The archives preserve fitted model state, anomaly maps and evaluation arrays.
MVTec-derived data, masks, maps and descriptors retain the MVTec AD dataset's
Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International terms;
see MVTEC_LICENSE.txt. These are research artifacts, not a commercial data license.

Dataset credit: Paul Bergmann, Michael Fauser, David Sattlegger and Carsten Steger,
MVTec Software GmbH, MVTec AD (CVPR 2019).
Source: https://www.mvtec.com/company/research/datasets/mvtec-ad
Changes: resize/crop-aligned masks, computed descriptors, fitted model parameters,
and anomaly-score maps, as documented in the reproduction source audit.

Author code remains separately pinned with its original licenses and attribution
in source_lock.json and the upstream repositories. These archives contain no
original MNIST, CIFAR-10 or MVTec input images. Code and archive data have distinct
provenance; no license on this repository overrides an upstream dataset license.
